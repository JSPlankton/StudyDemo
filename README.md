# 上海师范大学成考计划

这是一个面向手机竖屏的静态学习 PWA，用于上海师范大学成人高考专升本行政管理备考和入学后拿证跟踪。

## 打开方式

本地预览：

```powershell
python "C:\Users\admin\Desktop\上海师范大学成考计划\serve.py" --directory "C:\Users\admin\Desktop\上海师范大学成考计划" --port 4174
```

浏览器打开：

```text
http://127.0.0.1:4174/index.html
```

## 已包含功能

- 本地账号：可一键创建“我”和“老婆”，学习进度互不影响。
- 今日任务：英语每日必学，政治和高数（二）轮换推进，可点击进入当天课程。
- 学习库：内置原创课程笔记、例题、记忆卡片和随堂题。
- 日历：按月查看每天完成情况。
- 题库：支持日练、周考、月考、模拟、错题练习。
- 错题本：自动记录错题、答案和解析，可标记已复习。
- 统计：完成任务数、考试练习数、正确率、待复习错题。
- 备份：导出和导入 JSON。
- PWA：部署到 HTTPS 后可添加到手机主屏幕，并缓存核心文件。

## 数据边界

当前版本默认仍先把数据保存在当前浏览器的 `localStorage`。同一台手机同一浏览器内，“我”和“老婆”等本地学习账号会独立记录进度、错题和考试记录。

如果部署了 `sync_server.py` 并在 Nginx 上反代 `/api/`，页面顶部可以绑定一个“云同步账号”。这是无密码同步：同步账号本身就是私人同步码，知道它的人可以读取或覆盖云端进度。适合家庭自用，不适合作为公开多用户系统。

云同步服务需要 Python 3.6+，CentOS 服务器上建议使用 `python3 sync_server.py` 或 systemd 里的 `/usr/bin/python3`。

## 文件说明

- `index.html`：应用入口。
- `styles.css`：移动端样式。
- `src/content.mjs`：计划节点、知识库、题库。
- `src/app-core.mjs`：账号、计划、判分、统计、备份逻辑。
- `src/app.js`：浏览器交互。
- `src/sync-client.mjs`：无密码云同步的前端请求与账号校验。
- `sync_server.py`：SQLite 云同步 API 服务。
- `tests/app-core.test.mjs`：核心逻辑测试。
