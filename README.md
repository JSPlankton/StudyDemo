# 上海师范大学成考计划

这是一个面向手机竖屏的静态学习 PWA，用于上海师范大学成人高考专升本行政管理备考和入学后拿证跟踪。

## 打开方式

本地预览：

```powershell
python "C:\Users\admin\Desktop\上海师范大学成考计划\serve.py" --directory "C:\Users\admin\Desktop\上海师范大学成考计划" --port 4174
```

浏览器打开：

```text
http://127.0.0.1:4174/index.html
```

## 已包含功能

- 本地账号：可一键创建“我”和“老婆”，学习进度互不影响。
- 今日任务：英语每日必学，政治和高数（二）轮换推进，可点击进入当天课程。
- 学习库：内置原创课程笔记、例题、记忆卡片和随堂题。
- 日历：按月查看每天完成情况。
- 题库：支持日练、周考、月考、模拟、错题练习。
- 错题本：自动记录错题、答案和解析，可标记已复习。
- 统计：完成任务数、考试练习数、正确率、待复习错题。
- 备份：导出和导入 JSON。
- PWA：部署到 HTTPS 后可添加到手机主屏幕，并缓存核心文件。

## 数据边界

当前版本是纯前端本地账号，数据保存在当前浏览器的 `localStorage`。同一台手机同一浏览器内，两个账号可以独立记录进度；换设备或换浏览器不会自动同步。后续如果要外网登录和多设备同步，可以把 `src/app-core.mjs` 的状态对象接到云端数据库。

## 文件说明

- `index.html`：应用入口。
- `styles.css`：移动端样式。
- `src/content.mjs`：计划节点、知识库、题库。
- `src/app-core.mjs`：账号、计划、判分、统计、备份逻辑。
- `src/app.js`：浏览器交互。
- `tests/app-core.test.mjs`：核心逻辑测试。

## 官方信息

报名、缴费、准考证、查分、录取以“上海招考热线”和上海师范大学继续教育学院当年公告为准。目录里的 `03-官方渠道与报名流程.md` 已整理核验清单。
