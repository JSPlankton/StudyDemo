# 今日课程学习库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make each Today task open a concrete learning lesson with notes, examples, flashcards, in-lesson questions, and per-account completion records.

**Architecture:** Content stays in `src/content.mjs`; task-to-lesson selection and lesson completion live in `src/app-core.mjs`; the mobile UI in `src/app.js` adds a lesson view reachable from Today task cards. The feature keeps the current local-account state model and reuses existing quiz/wrong-book behavior where possible.

**Tech Stack:** Vanilla HTML/CSS/JavaScript ES modules, browser `localStorage`, Node built-in test runner.
