# SHNU Adult Exam Study App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a mobile-first static PWA study app for Shanghai Normal University administrative management adult-exam planning with local multi-account progress.

**Architecture:** A static HTML/CSS/JavaScript app stores all state in `localStorage`. Pure logic lives in `src/app-core.mjs` for Node test coverage, while `src/app.js` binds that logic to the mobile UI. Content data lives in `src/content.mjs` so future cloud sync can replace only storage/account plumbing.

**Tech Stack:** HTML, CSS, vanilla ES modules, Node built-in test runner, browser `localStorage`, Web App Manifest, Service Worker.

---

### File Structure

- `index.html`: mobile portrait app shell.
- `styles.css`: responsive visual system and component styling.
- `src/content.mjs`: timeline, subject metadata, knowledge cards, question bank.
- `src/app-core.mjs`: account, schedule, quiz, stats, import/export logic.
- `src/app.js`: browser UI controller.
- `manifest.webmanifest`: installable app metadata.
- `sw.js`: static asset cache.
- `tests/app-core.test.mjs`: Node tests for account isolation, schedule generation, quiz grading, statistics.
